# Homelessness Data Analysis

This repository contains data analysis projects examining homelessness in Los Angeles, with a focus on geographic patterns and conditions in Koreatown. The analyses use Python, R, Jupyter Notebooks, and R Markdown to explore datasets, identify trends, and create visualizations.

The repository includes exploratory notebooks, an R Markdown report, a Python script for Koreatown-focused analysis, source data, and generated figures. [1]
